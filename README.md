# 📊 Exploratory Data Analysis (EDA) on Titanic Dataset

## 📌 Project Overview
This project focuses on performing **data cleaning** and **exploratory data analysis (EDA)** on the **Titanic dataset** from Kaggle.  
The goal is to understand the dataset, explore relationships between variables, and identify meaningful **patterns and trends** that influenced passenger survival.

---

## 🎯 Objectives
- Clean the dataset by handling missing and inconsistent values  
- Perform exploratory data analysis using visualizations  
- Analyze relationships between features such as **gender, age, class**, and **survival**  
- Draw insights from project 

---

## 📂 Dataset Information
- **Dataset Name:** Titanic Dataset  
- **Source:** Kaggle  
- **Description:**  
  The dataset contains information about passengers aboard the Titanic, including:
  - Passenger class  
  - Sex  
  - Age  
  - Fare  
  - Survival status  

---

## 🛠️ Tools & Libraries Used
- Python  
- Jupyter Notebook  
- Pandas  
- NumPy  
- Matplotlib  
- Seaborn  

---

## 🧹 Data Cleaning Steps
- Checked dataset shape, columns, and data types  
- Identified missing values  
- Filled or removed missing data where necessary  
- Dropped irrelevant columns  
- Ensured consistency in categorical data  

---

## 📈 Exploratory Data Analysis (EDA)
The following analyses were performed:
- Survival distribution analysis  
- Survival comparison by **gender**  
- Survival comparison by **passenger class**  
- Age distribution analysis  
- Relationship between fare and survival  

### Visualizations Used
- Count plots  
- Histograms  
- Bar charts  

---

## 🔍 Key Insights
- Females had a higher survival rate compared to males  
- Passengers in **1st class** were more likely to survive  
- Children had a higher chance of survival  
- Higher ticket fares were generally associated with higher survival rates  

---

## 📌 Conclusion
This exploratory data analysis revealed important survival patterns in the Titanic dataset and demonstrated how **data visualization and analysis** can uncover meaningful insights from real-world data.
